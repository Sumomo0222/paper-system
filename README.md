# PAPER SYSTEM — 纸面系统 · 虚构高级文具品牌购物网站

> 「PAPER SYSTEM」是一家**虚构的**东京文具工房。所有品牌、商品、规格、价格与文案均为演示内容，
> 结算为纯前端模拟，不会向任何服务器发送数据，也不会产生真实扣款。

**在线访问：https://sumomo0222.github.io/paper-system/**

纯静态站点：无框架、无构建、无外部运行时依赖（字体自托管、商品图为内置矢量插画），任何静态托管都能直接部署。

## 功能一览

- **首页 = 桌面工作台**：像整理桌面一样，把文具从托盘拖上桌面垫自由摆放（桌面端鼠标拖拽 / 移动端点按托盘投放）；两件物品靠在一起自动编为一「组合」，可整组加购。
- **商品卡悬停规格**：桌面端悬停即滑出 纸张纹理 / 页型 / 尺寸 / 装订 规格层；移动端点按卡片上的「规格 +」展开。
- **商品详情**：封面颜色、纸张类型、内页格式（开本）、刻字（压凹）全部可组合，主图实时重绘、价格实时联动。
- **定制一本笔记本（定制工坊）**：开本 × 内页 × 页数 × 封面材质/颜色 × 装订 × 配件 × 刻字，右侧 LIVE PREVIEW 与价格明细实时更新，一键加入购物车（预览图随订单进购物车）。
- **分类筛选 / 排序 / 库存**：分类货架与列表页筛选排序；库存本地持久化，下单后自动扣减，售罄显示「补货中」并禁用加购，低库存显示「仅剩 N」。
- **购物车抽屉 / 模拟结算**：右侧抽屉管理数量与变体；三步模拟结算（收货信息校验 → 配送方式 → 支付方式），下单生成订单号与订单摘要。
- 桌面 / 移动双端适配，`prefers-reduced-motion` 友好。

## 设计系统

- 三色：米白 `#F4EFE3` / 石墨黑 `#1E1C17` / 钴蓝 `#0B49C0`（唯一强调色）
- 视觉母题：网格纸背景、装订孔、裁切标记（每张插画四角）、活版标签
- 字体：Archivo（自托管 latin 子集）+ IBM Plex Mono（自托管）+ 系统中日文字体栈

## 目录结构

```
index.html            页面外壳（顶栏 / 购物车抽屉 / 页脚）
css/style.css         全站样式
js/data.js            ★ 数据总配置：商品、分类、价格、规格、定制器、结算、文案（唯一需要日常编辑的文件）
js/art.mjs            商品矢量插画渲染器（详情页 / 定制器实时预览共用）
js/app.mjs            路由与全部交互逻辑
assets/img/*.svg      商品插画（由 tools/render-assets.mjs 从 data.js 批量生成）
assets/fonts/*.woff2  自托管字体
tools/render-assets.mjs   重新生成商品插画：node tools/render-assets.mjs
tools/screenshot.mjs      开发用截图工具（无界面 Chrome）
```

## 换成真实内容（三步）

1. **换图片**：把 `assets/img/<id>.svg` 换成同名照片文件，或直接改 `js/data.js` 里每件商品的 `img` 字段（支持任意路径/外链）。图片加载失败会自动回退到内置插画，不会白屏。
2. **改数据**：编辑 `js/data.js` —— 商品、价格、库存、分类、定制器配件与计价、配送费、品牌文案全部集中在这一个文件。
3. **部署**：整目录上传任意静态托管（GitHub Pages / 对象存储 + CDN / Nginx）。

改了商品插画相关的 `art` 字段后，运行 `node tools/render-assets.mjs` 重新生成卡片配图。
